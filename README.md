# Thai PUA Tool

ឧបករណ៍បង្កើតហ្វ៊ន្ត Thai PUA និងបំប្លែងអក្សរថៃ ↔ PUA សម្រាប់ហ្គេម។

## លក្ខណៈ

- **Option 1** បង្កើតហ្វ៊ន្ត `Thai_PUA.ttf` ពីអក្សរថៃក្នុងឯកសារ `.txt` ហើយបំប្លែងឯកសារទាំងនោះ
- **Latin Fallback Font** (optional) ចម្លងអក្សរអង់គ្លេស ប្រសិនបើហ្វ៊ន្តថៃដើមមិនមាន

## ក្បួនបំប្លែង

| ប្រភេទ | បំប្លែង? |
|---|---|
| ព្យញ្ជនៈដែលមានស្រះលើ ឬក្រោម (ិ ី ឹ ឺ ុ ូ ฺ ั) | ✅ បាទ/ចាស |
| ព្យញ្ជនៈដែលមាន ำ | ✅ បាទ/ចាស |
| ព្យញ្ជនៈដែលមានវរណយុត្ត (่ ้ ๊ ๋) | ✅ បាទ/ចាស (រួមជាមួយ) |
| ព្យញ្ជនៈធម្មតា (គ្មានសញ្ញា) | ❌ ទេ |
| ស្រះនាំមុខ (เ แ โ ใ ไ) | ❌ ទេ |
| ะ า | ❌ ទេ |
| ๅ | ❌ ទេ |

ឧទាហរណ៍ `ทำงาน` → បំប្លែងតែ `ทำ` ចំណែក `งาน` នៅដដែល។

## តម្រូវការ

- Windows 10 ឬ 11
- Python 3.10 ឬខ្ពស់ជាងនេះ (ជាមួយ tkinter)

ដំឡើងកញ្ចប់:
```
pip install fonttools uharfbuzz regex pillow
```

## ការប្រើប្រាស់

ដំណើរការ:
```
python main_thai.py
```

### Option 1 — បង្កើតហ្វ៊ន្តថ្មី

1. **Noto Sans Thai Font**: ជ្រើសហ្វ៊ន្តថៃ (`.ttf`) ឬ font ណាមួយដែលអ្នកចូលចិត្ត
2. **Text Folder**: ថតដែលមានឯកសារ `.txt` ដែលបានបកប្រែជាភាសាថៃរួចរាល់ (អានរួមថតរង)
3. **Output Folder**: ថតលទ្ធផល
4. **Start Codepoint**: `E000` (ប្រើ PUA)
5. **Latin Fallback Font**: `arial.ttf` ឬ `segoeui.ttf` (រកឱ្យស្វ័យប្រវត្តិ)
6. ចុច **GENERATE FONT**

ឯកសារលទ្ធផល:

| ឯកសារ | ការពណ៌នា |
|---|---|
| `Thai_PUA.ttf` | ហ្វ៊ន្តសម្រាប់ដាក់ក្នុងហ្គេម |
| `mapping.json` | តារាងផ្គូផ្គង អក្សរថៃ ↔ PUA |
| `thai_pua_list.txt` | `"អក្សរថៃ": "តួ PUA",` ម្ដងមួយបន្ទាត់ |
| `thai_pua_chars.txt` | តួ PUA ទាំងអស់ក្នុងបន្ទាត់តែមួយ (ដកឃ្លារវាងតួ) |
| `converted/` | ឯកសារ `.txt` ដែលបានបំប្លែង |

## ដាក់ហ្វ៊ន្តក្នុងហ្គេម

1. ចុចស្ដាំលើ `Thai_PUA.ttf` → **Install**
2. ក្នុងហ្គេម ជ្រើសហ្វ៊ន្តដែលមានឈ្មោះ Thai PUA
3. បើហ្គេមមិនឃើញ ដាក់ `Thai_PUA.ttf` ក្នុងថតហ្គេម

## ហ្វ៊ន្តមួយសម្រាប់ហ្គេមមួយ

⚠️ `Thai_PUA.ttf` និង `mapping.json` ដែលបង្កើតពីហ្គេមមួយ**មិនអាចប្រើសម្រាប់ហ្គេមមួយទៀតបានទេ** ព្រោះ:

- ហ្វ៊ន្តមានតែអក្សរ (ក្រុម​ព្យញ្ជនៈ + សញ្ញា) ដែលមាននៅក្នុងឯកសារ `.txt` របស់ហ្គេមនោះ
- កូដ PUA ត្រូវបានកំណត់តាមលំដាប់ក្នុងឯកសារនោះ ដូច្នេះហ្គេមផ្សេងនឹងមានកូដផ្សេង
- ហ្គេមផ្សេងអាចមានអក្សរថៃខុសគ្នា ដែលហ្វ៊ននេះមិនមាន

ដូច្នេះសម្រាប់ហ្គេមថ្មីនីមួយៗ សូម:

1. ដាក់ឯកសារ `.txt` ភាសាថៃរបស់ហ្គេមនោះក្នុងថតមួយ
2. ប្រើ **Option 1** ដើម្បីបង្កើត `Thai_PUA.ttf` និង `mapping.json` ថ្មី ព្រមទាំងបំប្លែងឯកសារនោះ
3. ដាក់ឈ្មោះ ឬថតលទ្ធផលដាច់ដោយឡែកសម្រាប់ហ្គេមនីមួយៗ កុំឱ្យច្រឡំ

## បង្កើត .exe

```
pip install pyinstaller
pyinstaller --onefile --windowed --name ThaiPUATool --collect-all uharfbuzz --collect-all fontTools main_thai.py
```

ឯកសារលទ្ធផល: `dist\ThaiPUATool.exe`

## បញ្ហាដែលអាចកើតឡើង

| បញ្ហា | ដំណោះស្រាយ |
|---|---|
| អក្សរថៃមិននៅកណ្ដាល ឬជាន់គ្នា | GENERATE FONT ឡើងវិញ ហើយប្រើ `mapping.json` ថ្មី |
| អក្សរថៃ**ធម្មតា**ត្រូវបំប្លែង | លុប `mapping.json` ចាស់ ហើយបង្កើតឡើងវិញ |
| ហ្គេមបង្ហាញអក្សរខុស ឬជាអក្សរចម្លែក | ប្រើ `Thai_PUA.ttf` និង `mapping.json` ដែលបង្កើតពី**ហ្គេមនោះ**ប៉ុណ្ណោះ |
| អក្សរអង់គ្លេសបាត់ក្នុងហ្គេម | ប្រើ Latin Fallback Font ហើយ GENERATE ឡើងវិញ |
| `AssertionError` | ចម្លង traceback ពី Log ទៅ issue |
| `Script file does not exist` (PyInstaller) | `cd` ទៅថតដែលមាន `main_thai.py` ជាមុន |
