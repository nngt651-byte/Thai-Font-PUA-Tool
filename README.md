# Thai PUA Tool
โปรดทราบว่านี่คือเครื่องมือสร้างฟอนต์ ไม่ใช่เครื่องมือแปลภาษา โปรดอย่าเข้าใจผิด
เครื่องมือสร้างฟอนต์ Thai PUA และแปลงข้อความไทย ↔ PUA สำหรับเกม

## ความสามารถ

- **Option 1** สร้างฟอนต์ `Thai_PUA.ttf` จากข้อความไทยในไฟล์ `.txt` แล้วแปลงไฟล์เหล่านั้น
- **Latin Fallback Font** (ไม่บังคับ) คัดลอกอักษรอังกฤษ หากฟอนต์ไทยต้นฉบับไม่มีอักษรเหล่านี้

## กฎการแปลง

ตัวอย่าง `ทำงาน` → แปลงเฉพาะ `ทำ` ส่วน `งาน` คงเดิม

## ข้อกำหนด

- Windows 10 หรือ 11
- Python 3.10 ขึ้นไป (พร้อม tkinter)

ติดตั้งแพ็กเกจ:
```
pip install fonttools uharfbuzz regex pillow
```

## การใช้งาน

เปิดโปรแกรม:
```
python main_thai.py
```

### Option 1 — สร้างฟอนต์ใหม่

1. **Noto Sans Thai Font**: เลือกฟอนต์ไทย (`.ttf`) หรือฟอนต์ใดก็ได้ที่ชอบ
2. **Text Folder**: โฟลเดอร์ที่มีไฟล์ `.txt` ที่แปลเป็นภาษาไทยเรียบร้อยแล้ว (อ่านรวมโฟลเดอร์ย่อย)
3. **Output Folder**: โฟลเดอร์ผลลัพธ์
4. **Start Codepoint**: `E000` (ใช้ PUA)
5. **Latin Fallback Font**: `arial.ttf` หรือ `segoeui.ttf` (ค้นหาอัตโนมัติ)
6. กด **GENERATE FONT**

ไฟล์ผลลัพธ์:

| ไฟล์ | คำอธิบาย |
|---|---|
| `Thai_PUA.ttf` | ฟอนต์สำหรับใส่ในเกม |
| `mapping.json` | ตารางจับคู่ อักษรไทย ↔ PUA |
| `thai_pua_list.txt` | `"อักษรไทย": "ตัว PUA",` บรรทัดละหนึ่งรายการ |
| `thai_pua_chars.txt` | ตัว PUA ทั้งหมดในบรรทัดเดียว (เว้นวรรคระหว่างตัว) |
| `converted/` | ไฟล์ `.txt` ที่แปลแล้ว |

## ฟอนต์หนึ่งชุดต่อหนึ่งเกม

⚠️ `Thai_PUA.ttf` และ `mapping.json` ที่สร้างจากเกมหนึ่ง**ไม่สามารถใช้กับอีกเกมหนึ่งได้** เพราะ:

- ฟอนต์มีเฉพาะอักษร (กลุ่มพยัญชนะ + เครื่องหมาย) ที่อยู่ในไฟล์ `.txt` ของเกมนั้น
- รหัส PUA กำหนดตามลำดับในไฟล์นั้น ดังนั้นเกมอื่นจะได้รหัสที่ต่างกัน
- เกมอื่นอาจมีอักษรไทยต่างจากที่ฟอนต์นี้มี

สำหรับเกมใหม่แต่ละเกม:

1. ใส่ไฟล์ `.txt` ภาษาไทยของเกมนั้นไว้ในโฟลเดอร์เดียวกัน
2. ใช้ **Option 1** เพื่อสร้าง `Thai_PUA.ttf` และ `mapping.json` ใหม่ พร้อมแปลงไฟล์นั้น
3. ตั้งชื่อหรือแยกโฟลเดอร์ผลลัพธ์สำหรับแต่ละเกมให้ชัดเจน จะได้ไม่สับสน
